개요(Instroduction)

도커 사용 목적 및 계기
개발자 각각 개인의 로컬 환경 또는 개발 환경, 운영 환경을 설정할 때 복잡하고 번거로운 작업을 했습니다.
물론 숙달이 되면 빠르게 작업할 수 있었지만 그렇다고 복잡하고 번거로운 작업이 줄어드는 것은 아니고
휴먼에러, 예상치 못한 에러가 발생하는 상황도 있었습니다.


그래서 컨테이너 플랫폼 도커를 활용해 로컬 환경, 개발 환경 및 운영 환경 등을 보다 손쉽고 일관되게 유지하는 방법을 정리하고자 합니다.

엔터프라이즈 웹 애플리케이션은 세 가지 종류의 서버로 구성하도록 하겠습니다.

  • 프론트엔드 소스를 제공하는 웹 서버
  • 비즈니스 로직을 수행하는 웹 애플리케이션 서버
  • 데이터를 저장하는 데이터베이스 서버

백엔드 애플리케이션에 대한 요청은 웹서버를 통해서만 접근이 가능합니다.
웹서버는 클라이언트와 백엔드 애플리케이션의 다리 역할을 하기 위해 프록시 기술을 활용합니다.

ARG python=python:3.13.1-alpine

FROM ${python} AS compile-image

# 필요한 패키지 설치
RUN apk add --no-cache postgresql-dev gcc musl-dev linux-headers && python -m venv /home/app/.venv

# Make sure we use the virtualenv:
ENV PATH="/home/app/.venv/bin:$PATH"

# Install dependencies:
COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

FROM ${python} AS build-image

COPY --from=compile-image /home/app/.venv /home/app/.venv

# Make sure we use the virtualenv:
ENV PATH="/home/app/.venv/bin:$PATH"

# Run the application:
COPY . /home/app

WORKDIR /home/app

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]
