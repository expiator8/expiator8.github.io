이벤트 루프

이벤트 루프(Event Loop)는 동시성 프로그래밍을 구현하는 방법중 하나인 비동기 프로그래밍 모델의 대표적인 메커니즘

이벤트

시스템 상태에서 감지 가능한 발생, 변화. 예시: 사용자 입력, 시스템 알림, data의 변화, 네트워크 응답

이벤트 루프는 이벤트가 큐에 들어가고 이를 순차적으로 처리하는 흐름 기본적으로 이벤트를 기다리거나 전송하는 프로그래밍 구조나 디자인 패턴

이벤트 기반 프로그래밍

프로그램 흐름이 외부 이벤트(마우스, 키보드, 다른 스레드의 알림, 기타 네트워크 이벤트 등)에 의해 결정되는 프로그래밍 방법

비동기 함수는 이벤트 기반 프로그래밍에서 이벤트를 발생시키는 함수로 볼 수 있음

javascript(브라우저 환경)에서의 이벤트 루프 동작

Call Stack : 자바스크립트 엔진이 코드 실행을 위해 사용하는 메모리 구조
Heap : 동적으로 생성된 자바스크립트 객체가 저장되는 공간
Web APIs: 브라우저에서 제공하는 API 모음으로, 비동기적으로 실행되는 작업들을 전담하여 처리한다. (AJAX 호출, 타이머 함수, DOM 조작 등)
Callback Queue : 비동기적 작업이 완료되면 실행되는 함수들이 대기하는 공간

Task Queue : setTimeout, setInterval, fetch, addEventListener와 같이 비동기로 처리되는 함수들의 콜백 함수가 들어가는 큐 (macrotask queue 혹은 task queue) Microtask Queue : promise.then, process.nextTick, MutationObserver 와 같이 우선적으로 비동기로 처리되는 함수들의 콜백 함수가 들어가는 큐 (처리 우선순위가 높음) Animation Frames Queue: 브라우저 애니메이션 작업에 대한 처리를 담당

이벤트 루프의 비동기 작업 처리 우선순위는 Microtask Queue → Animation Frames → Task Queue

즉, 비동기로 동작하는 핵심요소는 자바스크립트 언어가 아니라 브라우저라는 소프트웨어 내부의 Web APIs에서 처리 nodejs에서는 동작이 조금 다름

nodejs에서의 이벤트 루프 동작

Node.js에서는 비동기로 동작하는 핵심요소를 libuv 내장 라이브러리가 처리

V8 (JavaScript 엔진) : Node.js에서 사용하는 JavaScript 엔진으로 코드를 컴파일하고 실행
Bindings (Node API) : Node.js 시스템과 V8 엔진 간의 상호작용을 가능하게 하는 C++ 라이브러리
Libuv 라이브러리 : Node.js에서 비동기 I/O 작업을 처리하기 위한 C 라이브러리
Event Queue : 비동기 I/O 작업 결과를 저장하고 처리하기 위한 자료구조 (웹브라우저의 Task Queue와 유사)

import asyncio

async def fetch_data():
    print("Start fetching data...")
    await asyncio.sleep(2)
    print("Data fetched!")
    return "Sample Data"

async def process_data(data):
    print("Start processing data...")
    await asyncio.sleep(1)
    print(f"Data processed: {data}")
    return f"Processed {data}"

async def main():
    print("Starting main coroutine...")
    
    # Task 생성 및 예약
    task = asyncio.create_task(fetch_data())
    print("Task created and scheduled.")
    
    # Task 실행을 대기
    data = await task  # fetch_data coroutine의 결과를 기다림
    print("Task completed.")
    
    # 결과를 이용하여 다음 coroutine 실행
    processed_data = await process_data(data)
    print(f"Final result: {processed_data}")

# 이벤트 루프 실행
asyncio.run(main())
